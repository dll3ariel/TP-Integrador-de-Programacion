## Gestion de datos de Paises

Tranajo Practico Integrador de Programacion  -  Tecnicatura Universitaria en Programacion

## Descripcion del programa

Programa desarrollado en pythonn para administrar informacion sobre paises para guardar poblacion, superficie y contienete. Este permite ejectuar operaciones de alta, lectura, actualizaciocn y consulta (CRUD) asi tambien aplicar distintas fasetas de filtros, ordenamientos y calculos estadisticos que se guardan en un archivo CSV.

## Ejemplo de entradas y salidas

Primer ejemplo: Entrada de datos

Ingreso de un pais

===== GESTION DE DATOS DE PAISES =====
1. Listar todos los paises

3. Actualizar poblacion y superficie de un pais
4. Buscar pais por nombre
5. Filtrar paises
6. Ordenar paises
7. Mostrar estadisticas
8. Salir
Elegi una opcion del 1 al 8: 2

Agregar Pais
